--------------------------------------------------------------------------------
MİSAFİRHANE / TESİS EKLEME
--------------------------------------------------------------------------------

Dosya: rotalink-data → master_database_updated.json

Kök yapı:
{
  "tesisler": [ ... ],
  "geziler": [ ... ],
  "yemekler": [ ... ],
  "sosyal": [ ... ]
}

(Eski anahtar "misafirhaneler" de kabul edilir.)

Tek tesis örneği:
{
  "isim": "Ankara Misafirhanesi",
  "il": "Ankara",
  "ilce": "Çankaya",
  "adres": "Tam adres",
  "telefon": "0312...",
  "latitude": 39.92,
  "longitude": 32.85,
  "tip": "Misafirhane"
}

EŞLEŞME KURALI: Fiyat / adres / görsel dosyaları tesisle "il" + "isim" ile
eşleşir. İsim ve il yazımı birebir tutarlı olmalı.

Ayrıca yap (önerilen):
  1. fiyatlar.json → fiyat ekle
  2. tesisler_adres.json → adres/ilçe düzelt
  3. tesisler_gorseller.json → fotoğraf ekle

Gömülü yedek (uygulama içi):
  assets/data/master_database_updated.json
  GitHub erişilemezse kullanılır. GitHub'a attıktan sonra bunu da güncelle
  ve yeni sürüm çıkar.


--------------------------------------------------------------------------------
FİYAT EKLEME / GÜNCELLEME
--------------------------------------------------------------------------------

Dosya: rotalink-data → fiyatlar.json

{
  "tesisler": [
    {
      "il": "Ankara",
      "isim": "Ankara Misafirhanesi",
      "fiyat_sivil": "250 TL",
      "fiyat_kamu_personeli": "150 TL",
      "fiyat_kurum_personeli": "100 TL"
    }
  ]
}

- null veya boş → "Kalamaz"
- Alan yok → fiyat kayıtlı değil
- Anahtar alternatifleri: fiyatlar, items (liste kökü)


--------------------------------------------------------------------------------
ADRES / İLÇE GÜNCELLEME
--------------------------------------------------------------------------------

Dosya: rotalink-data → tesisler_adres.json

{

      "il": "Ankara",

      "adres": "Güncel adres",
      "ilce": "Çankaya"
    }
  ]
}

(items, tesisler, adresler anahtarları kabul edilir)


--------------------------------------------------------------------------------
TESİS GÖRSELİ EKLEME
--------------------------------------------------------------------------------
